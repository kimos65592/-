# ElectricitySmart
تطبيق Android أوفلاين لتسجيل قراءات عداد الكهرباء، الشحنات، وتحليل الاستهلاك والتوقعات.

## البناء
ارفع المشروع إلى GitHub، ثم افتح Actions وشغّل Build APK. ستجد ملف APK في Artifacts.

## التعريفة
التطبيق يحتوي على التعريفة المنزلية الرسمية بدءًا من استهلاك أبريل 2026، مع إمكانية تطوير إعدادات التعريفة المتقدمة لاحقًا.
